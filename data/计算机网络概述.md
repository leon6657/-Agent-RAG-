# 计算机网络知识点全景总结

> 从物理层到应用层，从经典理论到前沿技术，构建完整的计算机网络知识体系


## 一、计算机网络体系结构

### 1.1 基本概念

计算机网络是**将地理位置不同、具有独立功能的多个计算机系统，通过通信设备和线路连接起来，以功能完善的网络软件（协议、操作系统等）实现资源共享和信息传递的系统**。

### 1.2 关键性能指标

| 指标           | 定义                                                  | 单位         |
| -------------- | ----------------------------------------------------- | ------------ |
| **带宽**       | 网络通信线路传输数据的能力（数字带宽指最高速率）      | bps（bit/s） |
| **时延**       | 数据从一端传送到另一端所需时间（发送+传播+处理+排队） | 秒           |
| **时延带宽积** | 传播时延 × 带宽（衡量已发送但未确认的数据量）         | bit          |
| **RTT**        | 往返时间（Round-Trip Time）                           | 秒           |
| **吞吐量**     | 单位时间内实际传输的数据量                            | bps          |
| **丢包率**     | 丢失数据包占总发送包的比例                            | 百分比       |
| **PPS**        | 每秒数据包处理能力（对路由器等设备关键）              | pps          |

### 1.3 分层模型对比

#### OSI七层模型（法定标准）
- **应用层**：用户接口（HTTP/FTP/SMTP）
- **表示层**：数据格式转换、加解密、压缩
- **会话层**：建立/管理/终止会话
- **传输层**：端到端可靠传输（TCP/UDP）
- **网络层**：路由与寻址（IP）
- **数据链路层**：相邻节点可靠传输（MAC/PPP）
- **物理层**：比特流传输（电缆/无线）

#### TCP/IP四层模型（事实标准）
- **应用层**（对应OSI应用+表示+会话）
- **传输层**
- **网际层**
- **网络接口层**（对应OSI数据链路+物理）

#### 五层体系结构（教学常用）
- 应用层 → 传输层 → 网络层 → 数据链路层 → 物理层


## 二、物理层（Physical Layer）

### 2.1 核心职责
在传输媒体上透明传输比特流（不关心比特含义，只关心信号与速率）。

### 2.2 关键理论：奈奎斯特与香农

- **奈奎斯特采样定理**（无噪声）：理想低通信道极限速率 = 2W log₂V（W为带宽，V为信号电平级数）
- **香农公式**（有噪声）：信道极限速率 = W log₂(1 + S/N)

### 2.3 传输介质

**有线介质**：
- 双绞线（UTP/STP，1-10Gbps，100m）
- 同轴电缆（75Ω/50Ω，已较少用于局域网）
- 光纤（多模2km/单模100km，几十Tbps）

**无线介质**：无线电、微波、红外、激光（2.4GHz/5GHz/毫米波）

### 2.4 调制与编码

- **基带传输**（数字信号，局域网）
- **通带传输**（数字→模拟信号，无线/长距离）
- 常见编码：NRZ、NRZI、曼彻斯特、4B/5B、MLT-3
- 常见调制：ASK、FSK、PSK、QAM


## 三、数据链路层（Data Link Layer）

### 3.1 核心职责
将网络层数据报封装成**帧**，在相邻节点间可靠传输（差错控制+流量控制+访问控制）。

### 3.2 成帧方法
- 字符计数法
- 字符填充法（如PPP）
- 比特填充法（如HDLC的01111110）
- 违规编码法（如曼彻斯特）

### 3.3 差错控制

**检错**：
- 奇偶校验（只能检奇数位错）
- 校验和（Internet校验和，16位反码求和）
- CRC循环冗余校验（硬件实现，可检所有突发长度≤r的差错）

**纠错**：
- 海明码（可检错并纠错，码距≥3）
- 前向纠错FEC / 自动重传请求ARQ

### 3.4 流量控制与可靠传输协议

**停止-等待协议**：发送→等待ACK→发送，效率低（利用率 = T_data / (T_data + 2×T_prop)）

**后退N帧协议（GBN）**：连续发N帧，接收窗口=1，出错则重传该帧及之后所有帧

**选择重传协议（SR）**：接收窗口>1，只重传出错帧，需较大缓存

### 3.5 介质访问控制（MAC）

**信道划分**：FDMA（频分）、TDMA（时分）、CDMA（码分）、WDMA（波分）

**随机访问**：
- **ALOHA**（纯ALOHA吞吐量18.4%，时隙ALOHA 36.8%）
- **CSMA**（1-坚持/非坚持/p-坚持）
- **CSMA/CD**（以太网，边发边听，冲突停发）
- **CSMA/CA**（WiFi，先预约再发送）

**轮询访问**：令牌环、令牌总线

### 3.6 局域网与以太网

- **MAC地址**：48位（前24位OUI，后24位厂家分配）
- **以太网帧格式**：前导码7B + SFD 1B + 目的MAC 6B + 源MAC 6B + 类型/长度 2B + 数据 46-1500B + FCS 4B
- **交换机**：即插即用，MAC地址表自学习，隔离冲突域但不隔离广播域
- **生成树协议STP**：避免环路（IEEE 802.1D，收敛慢）/ RSTP（快速）/ MSTP（多实例）

### 3.7 点对点协议（PPP）
- 面向字节，支持认证（PAP/CHAP）
- 帧格式：标志7E + 地址FF + 控制03 + 协议 + 信息 + FCS + 标志


## 四、网络层（Network Layer）

### 4.1 核心职责
将数据报从源主机送到目标主机（路由选择+分组转发+拥塞控制+异构网络互联）。

### 4.2 IPv4协议

**IPv4地址**：32位，约43亿地址，点分十进制（如192.168.1.1）

**地址分类**：
- A类：0~127（/8），10.0.0.0/8私有
- B类：128~191（/16），172.16.0.0/12私有
- C类：192~223（/24），192.168.0.0/16私有
- D类：224~239（组播）
- E类：240~255（保留）

**特殊地址**：
- 0.0.0.0/8：本网络
- 127.0.0.0/8：环回测试
- 255.255.255.255：有限广播
- 主机号全0：网络地址；全1：广播地址

**子网划分与CIDR**：
- VLSM（可变长子网掩码）与CIDR（无类域间路由），路由聚合（最长前缀匹配优先）

### 4.3 NAT与IPv6

**NAT（网络地址转换）**：映射内网私有IP到公网IP+端口，支持NAPT同时映射数万连接

**IPv6**：128位地址（3.4×10³⁸个），冒分十六进制表示，无广播，强制IPsec，简化头部（40字节固定）

### 4.4 ARP与ICMP

- **ARP**：IP→MAC的解析，缓存机制，免费ARP用于IP冲突检测
- **ICMP**：差错报告与查询（ping使用Echo请求/应答，traceroute利用TTL超时）

### 4.5 路由算法与协议

#### 路由算法分类
- **静态**：手动配置，适合小网络
- **动态**：自适应，分距离向量（RIP）、链路状态（OSPF）、路径向量（BGP）

#### 内部网关协议（IGP）
- **RIP**：距离向量，基于跳数（≤15），UDP 520，30s更新，水平分割+毒性逆转防环
- **OSPF**：链路状态，基于带宽/时延，IP协议89，分层（AS→区域→骨干区），收敛快，VLSM/CIDR支持

#### 外部网关协议（EGP）
- **BGP**：路径向量协议，TCP 179，只求"可达"，策略路由，支持CIDR与聚合

### 4.6 IP组播与移动IP
- **IGMP**：管理组成员关系
- **组播路由协议**：DVMRP/PIM
- **移动IP**：归属代理+外地代理，隧道机制


## 五、传输层（Transport Layer）

### 5.1 核心职责
提供端到端的逻辑通信（复用/分用+差错检测+可靠/不可靠传输）。

### 5.2 UDP协议

| 特性           | 说明                                        |
| -------------- | ------------------------------------------- |
| 无连接、不可靠 | 尽最大努力交付，不保证顺序                  |
| 头部8字节      | 源端口(2B)+目的端口(2B)+长度(2B)+校验和(2B) |
| 面向报文       | 不拆分应用层数据，保留边界                  |
| 校验和         | 包含伪首部（源IP+目的IP+协议号+UDP长度）    |
| 适用场景       | DNS、DHCP、SNMP、RTP、实时音视频            |

### 5.3 TCP协议

#### 头部结构（20~60字节）
关键字段：源/目的端口（各2B）、序列号（4B）、确认号（4B，累计确认）、数据偏移（4位）、
标志位（URG/ACK/PSH/RST/SYN/FIN）、窗口大小（2B，流量控制）、校验和（2B）、紧急指针（2B）、选项

#### 可靠传输机制
- **校验和**：同UDP，含伪首部
- **序列号与累计确认**：确保有序且不丢
- **超时重传**（RTO自适应基于RTT估算）
- **快速重传**：收到3个冗余ACK即重传

#### 流量控制
**滑动窗口协议**：接收方通告窗口（rwnd），零窗口探测防止死锁

#### 拥塞控制（核心）

| 算法         | 机制                            | 关键参数                         |
| ------------ | ------------------------------- | -------------------------------- |
| **慢启动**   | 拥塞窗口（cwnd）指数增长        | 初始cwnd≈10MSS，ssthresh初始阈值 |
| **拥塞避免** | cwnd线性增长（每个RTT+1MSS）    | 达到ssthresh后切换               |
| **快速重传** | 收到3个重复ACK即重传            | 不等待超时，提高效率             |
| **快速恢复** | 重传后cwnd=ssthresh+3MSS（非1） | 配合快速重传                     |

**AIMD原则**：加性增、乘性减（拥塞时cwnd减半）

#### 连接管理（三次握手/四次挥手）

**三次握手**（防止失效连接请求造成资源浪费）：
1. CLOSED→SYN_SENT（SYN=1, seq=x）
2. LISTEN→SYN_RCVD（SYN=1, ACK=1, seq=y, ack=x+1）
3. SYN_SENT→ESTABLISHED（ACK=1, seq=x+1, ack=y+1）

**四次挥手**：
1. FIN_WAIT_1（FIN=1, seq=u）
2. CLOSE_WAIT（ACK=1, seq=v, ack=u+1）→应用程序关闭
3. LAST_ACK（FIN=1, ACK=1, seq=w, ack=u+1）
4. TIME_WAIT（2MSL等待，确保ACK到达）→CLOSED

#### TCP状态转换
共11种状态：CLOSED、LISTEN、SYN_SENT、SYN_RCVD、ESTABLISHED、
FIN_WAIT_1、FIN_WAIT_2、CLOSE_WAIT、LAST_ACK、TIME_WAIT、CLOSING


## 六、应用层（Application Layer）

### 6.1 核心协议

**DNS（域名系统）**：
- 端口53（UDP/TCP），分布式层次结构（根域→顶级域→二级域→子域）
- 递归查询与迭代查询，缓存机制，DNS污染与安全（DNSSEC）

**HTTP/HTTPS**：
- HTTP端口80，HTTPS端口443（TLS/SSL加密）
- 非持久连接（HTTP/1.0）vs 持久连接（HTTP/1.1 Keep-Alive）
- 管道化（HTTP/1.1）vs 多路复用（HTTP/2）
- 状态码：1xx信息、2xx成功、3xx重定向、4xx客户端错误、5xx服务器错误

**FTP**：
- 端口20（数据）/21（控制），带外控制
- 主动模式（服务器连客户端）vs 被动模式（客户端连服务器）

**电子邮件**：
- SMTP（端口25，推协议）+ POP3（端口110，离线，邮件下载后删除）或 IMAP（端口143，在线，保留服务器副本）
- MIME：扩展支持多媒体

**DHCP（动态主机配置协议）**：
- 端口67/68，UDP
- DORA四步：Discover→Offer→Request→Ack，支持地址重用与续租

**Telnet/SSH**：
- Telnet（端口23，明文，不安全）
- SSH（端口22，加密，替代Telnet）

### 6.2 P2P应用

- **BitTorrent**：种子文件+Tracker追踪器，分块交换（tit-for-tat激励机制）
- **DHT（分布式哈希表）**：Kademlia算法，去中心化，K距离（XOR）


## 七、网络安全（Network Security）

### 7.1 加密技术

**对称加密**（速度快，适合大数据）：DES（56位，已不安全）、3DES、AES（128/192/256位，常用）

**非对称加密**（慢，适合密钥分发/数字签名）：RSA（基于大数分解）、ECC（椭圆曲线，更高效）

**哈希函数**（完整性校验）：MD5（128位，已攻破）、SHA-1（160位，已弱化）、SHA-256（常用）

### 7.2 数字签名与证书
- 数字签名：私钥签名，公钥验证（身份认证+防抵赖+完整性）
- 数字证书：CA签发，X.509标准，SSL/TLS依赖

### 7.3 安全协议层次

| 层次       | 协议                 | 功能                      |
| ---------- | -------------------- | ------------------------- |
| 应用层     | PGP/S/MIME           | 邮件加密与签名            |
| 传输层     | TLS/SSL              | 端到端加密（HTTPS）       |
| 网络层     | IPsec（AH+ESP）      | 加密隧道或传输模式（VPN） |
| 数据链路层 | WPA2/WPA3（802.11i） | 无线网络加密（AES-CCMP）  |

### 7.4 常见攻击与防御

| 攻击类型             | 原理               | 防御手段                     |
| -------------------- | ------------------ | ---------------------------- |
| 窃听                 | 截获网络流量       | 加密（TLS/IPsec）            |
| 中间人（MITM）       | 双方之间拦截并转发 | 证书认证/公钥基础设施        |
| 拒绝服务（DoS/DDoS） | 大量请求耗尽资源   | 流量清洗/SYN Cookie/限流     |
| 欺骗（IP/ARP/DNS）   | 伪造身份或信息     | 源地址验证/DNSSEC/静态ARP    |
| 会话劫持             | 窃取Cookie/Token   | 使用HTTPS/HttpOnly/安全Token |
| 端口扫描             | 探测开放端口       | 防火墙/IDS/端口敲门          |


## 八、无线与移动网络

### 8.1 IEEE 802.11（WiFi）

**协议演进**：
- 802.11a（54Mbps/5GHz）/11b（11Mbps/2.4GHz）
- 802.11g（54Mbps/2.4GHz）
- 802.11n（WiFi 4，600Mbps，MIMO）
- 802.11ac（WiFi 5，6.9Gbps，MU-MIMO）
- 802.11ax（WiFi 6/6E，9.6Gbps，OFDMA，目标唤醒时间）
- 802.11be（WiFi 7，46Gbps，320MHz，多链路操作）

**CSMA/CA**（而非CD，因无线无法边发边听）：
- 虚拟载波监听（NAV）+ 物理载波监听
- 帧间间隔（SIFS/DIFS/PIFS）实现优先级
- RTS/CTS（可选）解决隐藏终端问题

### 8.2 移动通信

- 1G（模拟）→2G（GSM数字）→3G（CDMA，移动互联网）→4G（LTE-Advanced，OFDMA+MIMO，100Mbps+）→5G（eMBB/uRLLC/mMTC，10Gbps，1ms）

### 8.3 无线个域网（蓝牙/ZigBee）

- **蓝牙**：2.4GHz，主从架构，BR/EDR（经典）与BLE（低功耗）
- **ZigBee**：基于802.15.4，低功耗低速，Mesh组网


## 九、多媒体与新型网络技术

### 9.1 多媒体网络

**实时传输协议（RTP）**：基于UDP，提供时间戳和序列号（用于音视频同步）

**RTCP**：RTP控制协议，反馈QoS信息（丢包/延迟/抖动）

**SIP（会话初始协议）**：建立/修改/终止多媒体会话（VoIP）

**QoS机制**：
- 区分服务（DiffServ）：标记优先级（DSCP）
- 综合服务（IntServ）：RSVP预留资源
- 流量整形：漏桶（平滑突发）、令牌桶（允许一定突发）
- 队列管理：FIFO、优先级队列、WFQ、RED/WRED（主动丢弃，避免全局同步）

### 9.2 SDN（软件定义网络）

- **架构**：控制平面与数据平面分离
- **OpenFlow协议**：控制器与交换机通信接口
- 三大特征：转发与控制分离、集中控制、可编程网络
- 应用场景：数据中心网络、WAN流量工程

### 9.3 网络虚拟化

- **VLAN**（IEEE 802.1Q）：广播域隔离，支持4094个VLAN（12位VID）
- **VXLAN**：三层网络上的二层虚拟化（24位VNI，1600万租户），用于数据中心大二层
- **Overlay网络**：在物理网络上构建逻辑隧道

### 9.4 数据中心网络

- **拓扑结构**：Fat-Tree（胖树）、Spine-Leaf（脊叶架构，无阻塞）
- **负载均衡**：ECMP（等价多路径）
- **拥塞控制**：DCQCN（数据中心量化拥塞通知）、TIMELY


## 十、网络管理与运维

### 10.1 网络管理框架（FCAPS）
- Fault（故障管理）、Configuration（配置管理）、Accounting（计费管理）
- Performance（性能管理）、Security（安全管理）

### 10.2 SNMP（简单网络管理协议）
- **架构**：NMS（网络管理系统）+ Agent（代理）+ MIB（管理信息库）
- 版本：SNMPv1/v2c（团体名，明文）、SNMPv3（加密+认证）
- 操作：GET/SET/TRAP（主动告警）

### 10.3 网络测量工具

| 工具               | 用途               | 原理                    |
| ------------------ | ------------------ | ----------------------- |
| ping               | 测试连通性与RTT    | ICMP Echo               |
| traceroute/tracert | 追踪路由路径       | ICMP TTL超时+端口不可达 |
| iperf              | 测试带宽吞吐量     | TCP/UDP流量生成         |
| netstat/ss         | 查看端口与连接状态 | 内核套接字统计          |
| tcpdump/Wireshark  | 抓包分析           | 网卡混杂模式/BPF过滤    |
| telnet/nc          | 测试端口连通性     | TCP连接测试             |

## 十二、重点公式速查

| 公式                                       | 说明                     |
| ------------------------------------------ | ------------------------ |
| 信道利用率 = T_data / (T_data + 2×T_prop)  | 停止等待协议             |
| 信道吞吐率 = 窗口大小 × MSS / RTT          | TCP理想吞吐（近似）      |
| 循环冗余校验：R = 余数 [ x^r·M(x) / G(x) ] | CRC校验计算              |
| 海明码：2^r ≥ k + r + 1                    | r为校验位数，k为信息位数 |
| 信道容量（奈奎斯特）= 2W log₂V             | 无噪声数字信道           |
| 信道容量（香农）= W log₂(1 + S/N)          | 有噪声信道               |
| 时延带宽积 = 传播时延 × 带宽               | 衡量在途数据量           |
| 吞吐量 = 窗口大小 / RTT（简化）            | 受限于带宽和窗口         |
| 平均网络吞吐率 ≈ 拥塞窗口 / RTT            | TCP稳态吞吐估算          |
