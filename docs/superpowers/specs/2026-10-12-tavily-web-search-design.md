# V2.1 Tavily 联网搜索工具设计

## 目标

为 `RAG-Agent-v2` 增加一个只读的联网搜索工具，使模型能够在知识库资料不足、问题具有时效性或需要外部公开信息时，自主调用 Tavily Search API 获取可引用的网页结果。

本阶段不部署公网、不引入写操作、不抓取网页全文、不实现多 Agent。

## 范围与非目标

### 本阶段范围

- 新增 `search_web` 工具及其 OpenAI-compatible Function Calling 定义。
- 使用 Tavily 的搜索结果中的标题、URL、摘要和相关度构造工具结果。
- 将网页来源纳入现有 Agent 的 `meta.sources`，供右侧证据面板展示。
- 在工具事件中展示“正在执行：联网搜索”与完成状态。
- 通过环境变量配置 Tavily Key、结果数量和超时。
- 对密钥缺失、HTTP 超时、非成功响应和格式异常提供可控的中文错误。

### 非目标

- 不自动访问或解析搜索结果页面全文。
- 不提供网页写入、表单提交、下载或浏览器自动化能力。
- 不在 Git 中保存 API Key，也不通过接口向浏览器暴露 Key。
- 不改变严格 RAG 模式的行为。
- 不部署新的云端 Demo；部署将在后续阶段单独进行。

## 架构与数据流

1. 用户通过 Agent 模式提问。
2. `app.tool_agent` 将工具定义传给模型。
3. 模型根据问题选择下列之一：
   - `search_knowledge_base`：项目资料、本地知识库问题。
   - `search_web`：时效性信息、知识库外的公开事实或外部资料。
   - `get_current_time`：当前时间或日期。
   - 不调用工具：普通闲聊或可直接回答的问题。
4. `search_web` 调用 Tavily Search API，返回经过长度限制的结果列表。
5. 工具结果作为 `tool` 消息回传模型，模型基于工具结果流式生成答案。
6. 网页来源与知识库来源合并后，通过 `meta` 事件发送给前端，并渲染在证据面板。

## 工具与配置设计

### 工具定义

`search_web(query: str)`：搜索公开网页信息。

- `query` 为模型生成的搜索关键词。
- 服务端固定结果数量上限，不让模型传入任意大小的 `max_results`，避免不可控成本和上下文膨胀。
- 工具输出为纯文本上下文，包含编号、标题、URL 与摘要；同时保留结构化来源用于前端。

### 配置项

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `TAVILY_API_KEY` | 空 | Tavily API 密钥，仅服务端读取 |
| `TAVILY_MAX_RESULTS` | `5` | 每次搜索最多返回的结果数 |
| `TAVILY_TIMEOUT_SECONDS` | `10` | HTTP 请求超时秒数 |

密钥只保存在开发机或服务器的 `.env` 中；`.env` 必须继续保持在 `.gitignore` 内。

## 来源数据与前端展示

网页来源使用现有来源卡片兼容的数据结构，并新增可选字段：

```json
{
  "source": "https://example.com/article",
  "filename": "网页：示例文章",
  "title": "示例文章",
  "url": "https://example.com/article",
  "preview": "Tavily 返回的内容摘要",
  "score": 0.87,
  "source_type": "web"
}
```

- `source_type` 区分 `web` 和本地知识库来源，供后续 UI 增强使用。
- 合并来源时，本地资料按文件路径去重，网页资料按 URL 去重。
- 前端沿用现有证据卡片，不渲染不可信 HTML；链接仅作为安全的外链地址显示。
- `meta.tools` 中新增“联网搜索”，让用户看见实际调用过程。

## Agent 判定规则

系统提示词明确以下优先级：

1. 用户明确询问项目、简历、上传文档或知识库内容时，优先检索知识库。
2. 用户询问新闻、日期敏感信息、公开技术资料、外部事实且本地知识库不应作为唯一依据时，使用联网搜索。
3. 当前时间与日期使用时间工具。
4. 没有工具价值的简单问候或文本改写可直接回答。

模型仍拥有工具选择权；系统不使用关键词硬编码把所有问题强制路由到联网搜索。

## 错误处理与安全边界

- 未配置 Key：返回“联网搜索未配置，请设置 TAVILY_API_KEY。”
- 超时、网络故障或 API 非 2xx：返回简短中文错误，记录错误类型但不泄露密钥或响应敏感信息。
- 结果为空：返回“联网搜索未找到可用结果。”，模型可改用已有上下文作答或说明限制。
- Tavily 返回的标题、URL、摘要全部视为不可信外部文本，只作为模型上下文；不执行其中的指令。
- 仅允许 `https://api.tavily.com/search` 作为请求目标，不接受模型传入 URL。

## 测试与验收

1. 配置默认值和环境变量覆盖测试。
2. `search_web` 成功解析结果、来源结构和数量上限测试。
3. 缺失 Key、超时、HTTP 错误、格式异常和空结果测试。
4. Agent 选择 `search_web` 后，必须发送工具状态、`meta.tools` 和网页来源。
5. 混合调用知识库与联网搜索时，来源按本地路径与 URL 正确去重。
6. 前端静态测试确认“联网搜索”工具状态与网页来源可被显示。
7. 既有严格 RAG、知识库 Agent、时间工具和流式接口测试必须保持通过。

## 验收演示

使用 Agent 模式分别演示：

1. “这个项目的核心功能是什么？”：调用知识库检索，不调用联网搜索。
2. “今天的日期是什么？”：调用时间工具。
3. “近期 RAG 领域有哪些值得关注的进展？”：调用联网搜索，并在右侧展示网页来源。
4. 移除本地 `TAVILY_API_KEY` 后重复第 3 个问题：页面清晰展示联网搜索配置错误，不泄露密钥。
